1. Reach the instrument panel
{{ if .Values.ingress.enabled }}
   The console is exposed through an Ingress ({{ .Values.ingress.className }}):
{{- $scheme := ternary "https" "http" (not (empty .Values.ingress.tls)) }}
{{- $defaultPaths := list (dict "path" "/" "pathType" "Prefix") }}
{{- range .Values.ingress.hosts }}
{{- $host := default "<load-balancer-address>" .host }}
{{- range (default $defaultPaths .paths) }}
     {{ $scheme }}://{{ $host }}{{ .path }}
{{- end }}
{{- end }}

   An ALB or an Ingress controller can take a couple of minutes to publish an address:

     kubectl -n {{ .Release.Namespace }} get ingress encabulation-control-console -w
{{- else }}
   The console is ClusterIP only. Port-forward it:

     kubectl -n {{ .Release.Namespace }} port-forward svc/encabulation-control-console 8080:8080

   then open http://localhost:8080 . (`make console` from the repository root does the same.)
{{- end }}

2. Sign in

   Unauthenticated visitors get the `viewer` role and can watch, but not touch. The bootstrap
   `admin` and `operator` passwords were generated on first install and preserved on upgrade:

     kubectl -n {{ .Release.Namespace }} get secret {{ include "encabulator.appSecretName" . }} \
       -o jsonpath='{.data.bootstrap-admin-password}' | base64 -d; echo

     kubectl -n {{ .Release.Namespace }} get secret {{ include "encabulator.appSecretName" . }} \
       -o jsonpath='{.data.bootstrap-operator-password}' | base64 -d; echo

   Log in as `admin` or `operator` with those.

3. Start the factory

   Traffic starts stopped. Either turn it on from the Grammeters tab, or:

     kubectl -n {{ .Release.Namespace }} port-forward svc/cardinal-grammeter 8081:8080 &
     curl -XPUT localhost:8081/v1/traffic -H 'content-type: application/json' \
       -d '{"running":true,"rps":5,"pattern":"sine","periodSeconds":120}'

   Then run a scenario from the Scenarios tab. `grand-tour` narrates the whole thing.
